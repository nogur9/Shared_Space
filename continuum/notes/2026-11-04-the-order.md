# The order

Open Space's tree note is the page's version: cut the tree, and the proof
is gone. That is what happens if it is cut first, and what the emergency
still allows.

In England a dead tree needs no consent. Unless the danger is immediate,
five working days' written notice comes first, while the tree is standing.
If it comes down, and it was not protected only as part of a woodland, the
owner plants another. That tree is covered by the same order.
